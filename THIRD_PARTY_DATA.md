# Third-party data

The bundled country and administrative-area reference data is derived from
GeoNames country, first-order administrative division, and second-order
administrative division exports.

- Source: https://download.geonames.org/export/dump/
- License: Creative Commons Attribution 4.0
- Attribution: GeoNames (https://www.geonames.org/)

The data is bundled so country and district/county selection remains available
while field agents are offline.
